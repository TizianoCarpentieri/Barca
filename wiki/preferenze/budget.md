# Budget

## Acquisto (intervista 2026-08-04)

| Voce | Valore |
|------|--------|
| Nuovo vs usato | **Solo usato** |
| Max acquisto mezzo | **4.500 €** |
| Stretch acquisto | Poco più solo se “sogno della vita” (~5–5,5k eccezione) |
| Carrello | **Non previsto** |

## Gestione annua (intervista 2026-08-04)

| Voce | Valore |
|------|--------|
| Cap a testa | **≤ 1.200 €/anno** |
| Cap totale 3 bestie | **≤ 3.600 €/anno** |
| Cosa include il cap | **Tutte le spese possibili** di possesso/uso (canone, assicurazione, manutenzione, carburante, varate, imprevisti…) |
| Split | Implicito **1/3** finché non dicono altro (1.200 × 3) |

## Cosa **non** è nel tetto mezzo ma **sì** nel tetto annuo

- Posto barca **oppure** rimessaggio terra + varate  
- Assicurazione  
- Manutenzione ordinaria / antifouling se in acqua  
- Carburante uscite  
- Piccoli imprevisti  

## Modello TCO grezzo (da validare con preventivi)

Envelope annuo: **3.600 €**. Uso moderato.

### Scenario A — posto barca

| Voce | Ipotesi bassa | Ipotesi media | Note |
|------|---------------|---------------|------|
| Canone ormeggio 5–6 m | 800 | 2.000+ | Anzio: € ufficiali da telefonare; Lazio spesso non low-cost |
| Assicurazione RC (+furto?) | 150 | 400 | dipende valore/coperture |
| Manutenzione + imprevisti | 200 | 600 | usato low budget = più rischio |
| Carburante (mod. uscite) | 200 | 500 | 40 CV, uscite moderate |
| **Totale** | **~1.350** | **~3.500+** | Media alta **supera** 3.600 se ormeggio caro |

→ Posto barca **sostenibile solo se canone contenuto** (boa, affare, annuncio con posto, nautica sociale, porto minore). Banchina “cara” da sola può bruciare quasi tutto l’envelope.

### Scenario C — cantiere a terra

| Voce | Ipotesi bassa | Ipotesi media | Note |
|------|---------------|---------------|------|
| Piazzale terra annuo | 400 | 1.200 | da preventivo |
| Varata+alaggio × N uscite | 300 | 1.200 | se 8–15 uscite e 40–80€/op. sale in fretta |
| Assicurazione | 150 | 350 | |
| Manutenzione | 150 | 400 | meno fouling se sempre a terra |
| Carburante | 200 | 500 | |
| **Totale** | **~1.200** | **~3.650** | Ok se poche varate o forfait cantiere |

→ Terra conviene se uscite non troppe **oppure** pacchetto “stagione varate incluse”.

### Regola pratica

```
3600 €/anno ÷ 3 = 1200 € a testa  →  hard cap
canone_fisso + (costo_per_uscita × N) + assicurazione + buffer ≤ 3600
```

Con uso moderato, target sano: **canone fisso ≤ ~1.500–2.000 €/anno** così restano carburante e guasti.
