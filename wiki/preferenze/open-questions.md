# Open questions

Domande da chiudere con le bestie o con ricerca.

## Gruppo e uso

- [x] Budget mezzo: **≤4.500 € usato** (stretch minimo se sogno)
- [ ] Split costi tra le 3 bestie
- [ ] Budget annuo gestione (rimessaggio+assicurazione+carburante)
- [ ] Riserva lavori post-acquisto (consigliata 500–1500 € extra)
- [x] Mare, lago, o entrambi? Zona operativa principale? → **Mare, litorale laziale (Ardea/Pomezia; Anzio–Circeo–Fiumicino)**
- [x] Rimessaggio: **A/B/C aperti** (posto / carrello / terra); D ibrido ed E esclusi
- [ ] Dati per chiudere A/B/C: tariffe Anzio, preventivi cantiere, libretto auto+gancio, frequenza uscite
- [ ] Quante uscite/anno realistiche?
- [x] Patente: **nessuno**; ideale **restare senza** (valutazione residuale aperta)
- [x] No-patente è target d’uso normale (non solo “plus temporaneo”)

## Barca

- [x] Nuovo vs usato → **solo usato**
- [x] Tipologia: **no gommone**; **gozzo / open / lancia rigida** + copertura sole
- [ ] Fuoribordo vs entrofuoribordo?
- [ ] Lunghezza target (range metri)?
- [ ] Cabina/bagno: necessari o no?
- [ ] Priorità pesca vs day-cruise sociale quando confliggono?

## Logistica

- [x] Traino/carrello: **no** (servizi a pagamento all’occorrenza)
- [ ] Scelta finale rimessaggio: **posto barca (A)** vs **cantiere terra (C)** (+ numeri €)
- [x] Budget annuo: **≤1200€/testa all-in** (≤3600 totali); split tipico 1/3
- [ ] Preventivi reali canone A vs C nel cap
- [x] Intestazione: **da decidere** (non blocca la caccia all’usato)
- [ ] Chi gestisce manutenzione e pratiche?

## Normativa / sicurezza (ricerca)

- [ ] Limiti precisi potenza/cilindrata/lunghezza **senza patente** (IT) — fonti ufficiali
- [ ] Obblighi dotazioni e assicurazione per la fascia scelta
