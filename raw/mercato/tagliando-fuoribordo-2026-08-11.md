# Tagliando / manutenzione fuoribordo — snapshot 2026-08-11

Profilo: 4 tempi piccolo **9,9–15 CV** (piano A). Uso ricreativo, poche ore/anno.

## 1. Obbligo di legge?

**No.** Il Codice della nautica da diporto **non** impone un “tagliando periodico” come la revisione auto.

Cosa c’entra la legge:

- **Garanzia legale** beni di consumo: tipicamente **2 anni** dal venditore (Cod. consumo) — il costruttore può richiedere manutenzioni a manuale per non contestare la garanzia.
- **RC** e dotazioni restano obblighi separati (altre sezioni prospetto).
- Navigare con mezzo in condizioni palesemente insicure può rientrare in doveri generali di diligenza / sicurezza (responsabilità civile se si causa danno), ma **non** c’è bollo “tagliando scaduto” da Guardia Costiera.

Yamaha IT (pacchetti manutenzione fuoribordo): manutenzione a **ore di moto** o **cadenza annuale**; corretta manutenzione consente estensione garanzia (es. +3 anni oltre i 2 di legge se fatta come da programma officina).  
https://www.yamaha-motor.eu/it/it/service-support/manutenzione/manutenzione-marine/pacchetti-di-manutenzione/pacchetti-fuoribordo/

## 2. Quando si fa (prassi costruttori / guide)

| Momento | Prassi tipica |
|---------|----------------|
| Tagliando “zero” | ~**15–20 ore** dopo nuovo (manuale) |
| Ordinario ricreativo | **1 volta/anno** (fine inverno / inizio stagione) **oppure** ogni **50–100 ore** se si superano prima |
| Olio cambio piede | ogni **~100 ore** / annuale |
| Girante pompa acqua | controllo annuale; sostituzione spesso **~100–200 ore** o se pale “morta” |
| Dopo ogni uscita | risciacquo acqua dolce (cuffie), non è “tagliando” ma cura base |

Fonti: Onautica 11/06/2026 guida tagliando; MagellanoStore costi (2023, ancora citata); forum/prassi 100 h girante.

## 3. Cosa include un tagliando ordinario

1. Risciacquo circuito (cuffie)  
2. Cambio **olio motore** + **filtro olio** (4T)  
3. Cambio **olio piede / gear**  
4. Controllo/sostituzione **candele**  
5. Controllo **girante** (e sostituzione se serve)  
6. Filtri benzina / tenute  
7. **Anodi** (zinchi) se consumati  
8. Ingrasso / spray protettivo parti esterne  

## 4. Costi osservati (indicativi, non preventivo Lazio firmato)

### Fai-da-te materiali (piccolo 4T 9.9–15 CV)

| Voce | € stima |
|------|---------|
| Olio motore 4T marino (0,8–1,5 L tipici piccoli) | 8–20 |
| Filtro olio | 5–15 |
| Olio piede / gear (poco volume) | 10–15 / intervento |
| Candela | 5–15 |
| Kit girante | 30–60 |
| Anodo piccolo | 10–30 |
| **Totale DIY annuale “base”** (senza girante nuova ogni anno) | **~40–90** |
| **DIY + girante** | **~70–140** |

Magellano (articolo costi, es. su motori anche più grandi): officina cambio olio **150–180 €** su **150 hp** → su 10–15 hp officina attesa **più bassa**.

### Officina / dealer (stima scala piccolo fuoribordo)

| Pacchetto | € stima |
|-----------|---------|
| Tagliando annuale base (olio+filtri+piedi+check) | **80–180** |
| Tagliando completo + girante + anodi | **150–280** |
| Solo manodopera se porti pezzi | variabile |

**Target TCO gruppo (3 soci):** ~**100–150 €/anno** officina **oppure** ~**50–80 €** DIY → **~1,5–4 €/testa/mese**.

## 5. Cura continua (quasi a costo zero)

- Risciacquo dopo sale  
- Non stoccare a lungo con benzina vecchia (stabilizzante se serve)  
- Controllare girante se surriscalda / allarme temp
